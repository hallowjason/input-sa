# Input-sa v3.1.1

包含 [v3.1.0 的新版偏好設定、Codex／Claude 文字整理及中英專名提示](https://github.com/hallowjason/input-sa/releases/tag/v3.1.0)，並修正安裝更新時的退出死結。

- 安裝器要求關閉 App 時，先離開主佇列的訊號回呼，再由 RunLoop 啟動正常終止；歷史寫入與 CLI 程序能完成收尾。
- 保留原本服務選擇、快捷鍵、個人字詞庫、錄音面板角色與簽章身分。
- 模型工具重用已安裝的 Whisper 模型，避免開發資料夾再存一份大型模型。

獨立 AppKit 回歸程序已重現舊行為逾時，修正版在 0.35 秒內正常退出。完整 macOS 編譯與獨立審查通過；本機正式版收到 SIGTERM 後約 0.09 秒正常退出，重新啟動後事件攔截器啟用，字詞庫、服務選擇與模型比對一致。介面與整理功能沿用 v3.1.0 已通過的 13 套測試、364 項檢查及 30 組排版驗證。

若從 v3.0.0／v3.1.0 更新時出現「Installed Input-sa did not exit」，舊安裝仍會保留。先由選單列正常結束 Input-sa 再更新；若已卡在退出狀態，確認沒有錄音或處理工作後，於活動監視器結束該 Input-sa 程序，再重試安裝。

公開 zip 不含大型語音模型；模型管理方式與 CLI 相容性限制同 v3.1.0。
