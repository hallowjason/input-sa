# UI 驗收紀錄

- 2026-09-19：使用者接受 Talky 風格，但指出偏好設定多處文字被截斷。外觀預覽不能只檢查配色與卡片；需逐頁使用長名稱、長說明驗證換行、列高、輸入欄寬與捲動可見性，並分別檢查淺色、深色及較小視窗。不要將單行省略號視為完整內容的替代。
- 同次回饋指出分頁圖示偏位與角色下拉選單太擠。自繪外觀必須同步安排內容內距；圖示與標題要以同一組置中，選單預留箭頭空間，表單控制項統一對齊，不能只依賴原生 cell 的預設位置。

- 原生 App 的 `.terminateLater` 會進入巢狀 run loop；不要從主 GCD callback 直接 terminate，否則排在主佇列的收尾 reply 可能無法執行。安裝驗證要實際測 SIGTERM 退出與重新啟動，不只驗簽章與啟動。
- 工作路徑減量先分類：可再生 build、遠端 checksum 完全相同的舊包、必要輸入、獨有備份。大型模型共用正式安裝路徑，避免為了整理而新增同步服務或破壞離線功能。
