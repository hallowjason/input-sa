# Input-sa v3.0.0

這版整合 Talky 的操作思路，保留 Input-sa 的快捷鍵與既有設定，讓錄音、翻譯和找回原稿更直接。

- **保留觀音角色的精簡錄音面板**：420 × 156 HUD，左側保留觀世音菩薩圖像與輕浮動，右側顯示字幕；同時呈現整理強度、錄音狀態與音量。本地 Whisper 支援暫時字幕，停止後再辨識完整錄音。
- **通用編號字詞庫**：取消道場切換，保留舊詞條；詞庫作為辨識／AI 拼寫參考，移除容易把正確內容改壞的同音強制替換。
- **八語言翻譯面板**：英、日、韓、泰、越南、印尼、西班牙、法文直接點選，各 App 分別記住選擇。
- **同段自然改口**：「三點，啊不對，是四點」在 AI 整理或翻譯時採用更正後內容；不修改上一次已貼出的文字。
- **可選本地 Whisper Turbo**：新增 large-v3-turbo 與模型管理，支援進度、暫停續傳、大小及 SHA-256 驗證。既有 Groq、Google、SenseVoice／Paraformer 保留，不自動變更你的引擎選擇。
- **原稿紀錄與三種強度**：原文、輕整理、結構整理可選；本機紀錄可比較及複製模型原文、繁體原稿、AI 結果與實際輸出。最多 200 筆／2 MB，不存錄音，可停用或清空。
- **取消與跨 App 保護**：取消後不貼字，晚到結果作廢；處理期間切換 App 時保留於剪貼簿並提示。整理失敗可找回辨識稿，翻譯失敗不把原稿當作譯文輸出。
- **安裝與打包改善**：固定簽章、驗證新舊身分、保留安裝備份，發布產物附 SHA-256；本機建置與公開套件分開，升級保留資料與已下載模型。

公開 zip **不包含大型語音模型**。首次使用本地 Whisper，請到「偏好設定 → 語音服務 → 管理模型…」下載約 1.6 GB 模型；需要 Apple Silicon 與 macOS 14 以上。主程式最低 macOS 12；Apple 本地整理另需 macOS 26 與 Apple Intelligence。選擇「原文」不呼叫 AI，因此會保留口頭改口過程。

已通過 11 套隔離測試、真實 Whisper runtime 測試、原生介面檢視及程式審查。尚無使用者個人錄音與正確逐字稿的比較基準，**不宣稱換引擎後準確率必然提升**；合成或公開音訊測試不能代表每個人的口音與使用情境。
