# Input-sa v3.1.0

這版更新偏好設定的整體布局，新增 Codex／Claude 文字整理選項，並補上中英夾雜時的專有名詞提示。

- **新版偏好設定**：一般／進階分組、膠囊分頁、柔和灰白與石墨灰表面、圓角浮雕卡片；保留 Input-sa 觀音識別、快捷鍵、詞庫、模型管理、AI 模式與使用統計。
- **排版修正**：長名稱與說明自動換行、清單列高依內容調整、視窗可縮放；修正分頁圖示偏位、下拉選單內距與快捷鍵欄位對齊，並改善深色選取標記。
- **可選文字整理服務**：在「進階 → 語音服務」選 Gemini、Apple 本地、Codex CLI 或 Claude Code。CLI 沿用本機既有登入，提供內建範例句的連線測試；翻譯與口頭加詞仍使用 Gemini。
- **取消與回退**：CLI 每句獨立執行，具備輸入／輸出限制、逾時、取消與程序回收；原稿不放在程序參數，整理失敗保留辨識稿。
- **中英專名提示**：本地 Whisper、Groq、Google STT 在辨識階段參考限量詞庫與 Codex／Claude 拼寫；只使用完整詞項並限制長度。
- **保守文字整理**：補上相同名稱的 AI 拼寫參考；保持一般 cloud／code 等英文，不加入強制同音替換。
- **引擎能力說明**：設定內明確區分 SenseVoice 的快速本地辨識與 Whisper 的詞庫提示、暫時字幕支援，保留既有引擎與帳號設定。
- **開發資料夾減量**：模型工具預設重用 App 已安裝的 Whisper 模型，避免多存約 1.6 GB；日常建置沿用現成引擎，不新增常駐服務或額外 UI 框架。

SenseVoice／Paraformer 目前的解碼方式不支援辨識提示；若英文名稱常聽錯，可在「進階 → 語音服務」試用本地 Whisper Turbo。模型管理與下載方式沿用 v3.0；公開 zip 不含大型模型。

CLI 相容性：Codex 目前驗證 0.154.0（文字整理模型 `gpt-5.5`）；兩家接法均限未受組織政策管理的個人登入。其他 Codex 版本或受管理帳號會提示不相容，口述保留辨識稿。

辨識驗證：Gemini 合成文字測試確認 Codex／Claude 與 cloud／code 保留，在明確語境下可還原音譯名稱。Whisper 合成音訊的提示前後比較未穩定恢復英文名稱，不能宣稱已提升個人錄音的整體準確率；仍需實際錄音與正確稿比較。

介面驗證：五分頁 × 三種視窗尺寸 × 淺／深色，共 30 組文字尺寸檢查通過；原生預覽確認長名稱、完整說明、分頁圖示、角色選單與快捷鍵對齊。CLI 測試按鈕的取消與恢復狀態已實際操作驗證。

程式驗證：13 套隔離測試、364 項檢查（含 CLI 79 項）通過；Codex／Claude 都能用既有登入整理內建合成句。完整 macOS 編譯與獨立程式審查通過。
