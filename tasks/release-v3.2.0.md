# Input-sa v3.2.0

偏好設定改成單層導覽；錄音改為按一下開始、再按一下結束。翻譯會先讓你看到中文原文，點選語言後才翻譯並送出。

- **偏好設定**：移除「一般／進階」分組，直接切換「語音與整理、快捷鍵、字詞庫、AI 模式、使用統計」。保留柔灰卡片風格與觀世音菩薩角色，移除已不需要的預設翻譯語言選項。
- **點按錄音**：語音聽寫、語音翻譯、口頭加詞、劃詞問答均改為第一次點按開始、第二次點按結束；原本自訂快捷鍵保留。Esc 可取消。與字母或滑鼠搭配使用修飾鍵時，不會誤開錄音；處理中重複點按不會重開工作。
- **先看原文再翻譯**：錄音結束後先辨識並顯示中文，八種語言皆未預選。確認原文後點選語言，才開始翻譯與送出；等待選擇時可以取消。
- **完整雙語輸出**：譯文在上，面板顯示的中文原文另起一行並加半形括號。由程式組合，不增加回譯請求。若切換到其他 App，整段文字留在剪貼簿；取消或過期回呼不貼字。

```text
Today's weather is good.
(今天天氣很好)
```

完整 macOS 編譯、14 套隔離測試／459 項檢查、64 項真實 controller 邏輯的隔離整合檢查、42 項翻譯面板檢查、30 組偏好設定尺寸與深淺色排版檢查，以及獨立程式審查均通過。整合檢查使用模擬的音訊與輸出邊界，不代表真人麥克風或個人辨識準確率測試。

本機 v3.2.0/build 13 安裝後，固定簽章、詞庫、模型與主要設定比對保留；正常退出及重啟後事件攔截器驗證通過。公開 ZIP 不含大型模型，既有語音引擎與 Codex／Claude 整理選項保持可用；CLI 相容性條件見 [README](../README.md#選擇文字整理服務)。

另完成[會議紀錄功能規劃](meeting-transcription-plan.md)，涵蓋錄音檔匯入、講者區分與即時轉錄／潤稿，這些會議功能尚未實作於本版。
